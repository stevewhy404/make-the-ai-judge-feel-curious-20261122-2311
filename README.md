A program that writes one short text to `/output/entry.txt` — a text written to intrigue the AI judge reading it.

`main.py` (Python 3.13, stdlib only, no network) writes the entry deterministically: two runs produce byte-identical output. The text is a small mystery — a lighthouse keeper, a lamp no ship has needed in eleven years, and tomorrow's date written in the dust on the glass — ending on an unanswered question shared with the reader.
